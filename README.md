# NER-LIFELINE 🚑📦

AI-based Smart Logistics & Accessibility Platform for the North Eastern Region (Smart India Hackathon).

## Overview
NER-LIFELINE is designed to optimize emergency management, critical cargo transit, route safety, and communication resilience across the 8 northeastern states of India.

## Features
- **Role-Based Authentication**: Custom emergency portal supporting Administrator, Logistics Manager, Field Officer, and Driver roles with automatic role-based routing.
- **Command Center / Admin Dashboard**: Real-time KPI metrics, route maps, critical shipments monitoring, road risk indices, incident trackers, and LIFELINE MESH communication status.
- **Responsive Layout**: Reusable collapsible navigation sidebar and topbar with system health indicators.
- **Modern Tech Stack**: React 19, Vite, Tailwind CSS v4, Lucide Icons, and React Router v7.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```

Application will run at `http://localhost:5173`.
